# 左文右题 · 四六级英语学习平台

## 作品介绍

### 一、作品简介

「左文右题」是一款面向大学英语四六级（CET-4 / CET-6）备考者的**全流程英语学习平台**。它以「左边读原文、右边答题」的双栏独立滚动刷题体验为核心，把**真题阅读、听力训练、生词管理、词书背诵、闯关游戏、AI 批改、写作创作、错题复盘、排行榜**等能力整合在一个产品里，覆盖「输入—记忆—输出—复盘」的完整学习闭环。

作品在线地址：https://cet-reading-82947.app.workbuddy.host/?sharecode=XRRLK7HGZP

### 二、核心功能

#### 1. 双栏独立滚动刷题（产品地基）

- 左边滚动原文、右边答题，**两栏滚动互不干扰**——滚左栏右栏不动，切题时左栏位置也保持不变。
- 手机端（<768px）自动切换为「文章 / 题目」Tab，两个容器始终留在 DOM 里，滚动位置天然保留。
- 支持键盘全流程操作：`1-4` 选答案、`Enter` 提交、`Space` 展开解析、`→` 下一题。

#### 2. 点词即查 + 生词闭环

- 点任意单词即弹词卡，查词走三级链路：`词典缓存 → 内置离线词库 → AI 生成释义`，同一词只真正查一次。
- 查过的词自动进入生词本，按记忆曲线循环复习；「认识 3 次」自动移出复习队列。
- 生词本支持词表 / 刷词 / 随身听三种复习方式。

#### 3. 词书与背单词

- 内置四六级高频词书（四级 1500 词、六级 1500 词、四六级必备核心 800 词），**无需导入即可直接背**。
- 支持自建词本、改名、删除、设默认、加词；阅读中遇到的生词自动归入「阅读生词」。
- 背词采用「先认词 → 四选一验证 → 连对 3 次过关 → 6 个一轮 → 回顾」的记忆节奏，干扰项为近义词级别，靠排除法蒙不过去。

#### 3.1 单词串成故事（AI 语境记忆）

- 把生词本/词书里勾选的单词交给 AI 串成一篇英文小故事，目标词加粗并紧跟中文释义，边读故事边记词。
- 支持「随机选词」与「手动勾选 4–16 个词」（勾选顺序即词序），来源可切生词本与任意词书。
- 整篇故事由服务端 TTS 合成一篇 MP3，走系统媒体通道 + Media Session，**熄屏后仍可继续收听**。

#### 4. 闯关游戏（趣味背单词）

内置十余个小游戏（词义消除、翻牌配对、拼写达人、听音辨词、打地鼠、贪吃蛇、保卫战、消消乐、听写等），把背单词变成闯关，寓教于乐。

#### 5. 听写 / 听力训练

支持听力原文播放与听写练习，音频随题跟随（点题自动定位到对应音频位置）。

#### 6. AI 批改与问答

- 写作、翻译题支持 AI 批改，输出分数与逐条评语。
- 每道题可「问 AI」，AI 结合当前题目的原文段落作答（上下文注入 + 流式输出）。
- 无 AI Key 时自动降级为模拟流式，功能不中断。

#### 7. 私密笔记

- 每道题可写自己的笔记，默认仅自己可见（服务端强制鉴权），可主动公开。
- 公开后不可撤回，权限控制严谨。

#### 8. 错题复盘与排行榜

- 错题自动归集，支持 AI 解析。
- 排行榜按生词量、正确率等维度排行，激励坚持学习。

#### 9. 创作中心（Agent 工作台）

- 提供小说创作、视频脚本等写作入口，扩展学习到「输出」环节。
- 内置 Agent 工作台：拍照搜题（图片 → AI 解题）、AI 创作（小说/脚本多模型通道）、内容导出（字幕 / 视频合成 / 文档导出），串联成「创作—导出—发布」链路。

### 三、技术栈

| 层 | 选型 |
|---|---|
| 框架 | Next.js 15（App Router）+ React 19 + TypeScript（strict） |
| 样式 | Tailwind CSS v4 + 自定义设计令牌 |
| 数据 | Prisma 6 + SQLite（18 张表；切 PostgreSQL 只改两处） |
| 认证 | NextAuth v5 Credentials + bcrypt + JWT Session |
| 状态 | zustand（刷题页局部状态）+ SWR（服务端数据） |
| 校验 | zod（所有 API 入参） |
| AI | OpenAI 兼容协议（默认 DeepSeek，可切通义/智谱/Moonshot），无 Key 自动降级 |
| 语音 | msedge-tts（单词/文章朗读） |

### 四、工程亮点

1. **答案不下发首屏**：题干和选项与答案/解析分离，`POST /api/answers` 提交后才换取，防止前端拿到答案。
2. **私密笔记服务端强制鉴权**：`visibility = private` 的查询条件硬编码为 `userId = 当前登录用户`，前端拿不到他人私密数据。
3. **留言 XSS 双重防护**：写入前白名单清洗（剥标签、控制字符、零宽字符），渲染时走 JSX 文本节点。
4. **查词三级缓存**：每级命中都回写缓存，同一单词只真正查一次。
5. **完善的自动化验收**：49 项接口级断言 + 21 项浏览器级断言，覆盖鉴权、判题、私密隔离、生词规则、查词、AI 流式、两栏滚动等。

### 五、快速开始

```bash
cd cet-reader
npm install
npm run setup          # prisma generate + 建表 + 灌种子数据
npm run dev            # http://localhost:3000
```

演示账号：`demo@cet.local` / `demo1234`（种子数据自带）
