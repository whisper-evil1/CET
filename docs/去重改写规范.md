# 定点改写规范（题材去重专用）

卷面正文里同一题材被写得太多时，用这份规范整篇换掉重复的那一篇，**不改卷子结构、不改其它篇目**。


## 你要改什么

`data/papers/<卷 id>.json` 是一个 JSON，`sections` 是数组，里面按顺序是：

| 下标 | type | 说明 |
| --- | --- | --- |
| 0 | writing | 写作（1 篇 1 题，题号 0） |
| 1 | reading | 阅读（固定 4 篇，`passages[0..3]`） |
| 2 | translation | 翻译（1 篇 1 题，题号 56） |

去重只改 `sections[1].passages[k]` 这一个对象，`order`/`title` 保持原样。**同文件的其它 passage、写作、翻译、顶层字段一律不动。**

## 三种篇目的硬格式

### passages[0]：Section A 选词填空（10 题，26–35）

```json
{
  "order": 1,
  "title": "Section A 选词填空",
  "paragraphs": [{ "label": "A", "text": "..." }, { "label": "B", "text": "..." }],
  "questions": [
    {
      "number": 26,
      "stem": "Choose the word for blank 26.",
      "options": [
        { "key": "A", "text": "..." },
        { "key": "B", "text": "..." },
        { "key": "C", "text": "..." },
        { "key": "D", "text": "..." }
      ],
      "answer": "B",
      "analysis": "中文解析",
      "type": "选词填空",
      "evidencePara": "A",
      "evidenceText": "..."
    }
  ]
}
```

- 正文 2–3 段、≥150 词（四级）/ ≥180 词（六级），段内依次出现 `26______` `27______` … `35______` 十个空号，数字紧贴下划线、顺序不能乱、不能缺号。
- 10 题题号 26–35 连续；每题 4 个选项 A–D，只有 1 个是该空正确词，其余 3 个同词性、搭配不对。
- **10 个正确词必须互不相同**；干扰词不得与任何正确词重复（导入器要用它们合成 A–O 十五词词库）。

### passages[1]：Section B 长篇阅读匹配（10 题，36–45）

```json
{
  "order": 2,
  "title": "Section B 长篇阅读匹配",
  "paragraphs": [{ "label": "A", "text": "..." }, { "label": "B", "text": "..." }],
  "questions": [
    {
      "number": 36,
      "stem": "一句从原文某段概括的英文陈述（抽象改写，不要照抄原句）",
      "options": [
        { "key": "A", "text": "Paragraph A" },
        { "key": "B", "text": "Paragraph B" }
      ],
      "answer": "C",
      "analysis": "中文指出对应段落哪句话",
      "type": "匹配题",
      "evidencePara": "C",
      "evidenceText": "..."
    }
  ]
}
```

- 段落 6–8 段，label 依次 A/B/C…；段内不要再写字母；正文合计 ≥250 词（四级）/ ≥280 词（六级）。
- 10 题题号 36–45；**选项数等于本篇段落数**，text 写 `"Paragraph X"`；`answer` 必须是本篇存在的段落字母。
- 答案要覆盖多个段落，同一段最多用两次。

### passages[2] / passages[3]：Section C 仔细阅读（一）/（二）（各 5 题）

`passages[2]` 题号 46–50，`passages[3]` 题号 51–55。

```json
{

  "title": "Section C 仔细阅读（一）",
  "paragraphs": [{ "label": "A", "text": "..." }],
  "questions": [
    {
      "number": 46,
      "stem": "英文题干",
      "options": [
        { "key": "A", "text": "..." },
        { "key": "B", "text": "..." },
        { "key": "C", "text": "..." },
        { "key": "D", "text": "..." }
      ],
      "answer": "C",
      "analysis": "中文解析",
      "type": "细节题",
      "evidencePara": "B",
      "evidenceText": "..."
    }
  ]
}
```

- 正文 4–6 段、≥250 词（四级）/ ≥280 词（六级）；5 题连续题号；四选一；`title` 里「（一）」「（二）」要与 `passages[2]`/`passages[3]` 对应。

## 内容要求

- 英文地道、符合级别难度；六级要有长难句、抽象概念、推断/态度/词句含义类题干。
- 具体、有据：写真实存在的研究、数据、机构、城市、年份，不要写「研究表明」这种空话。
- 干扰项要像真的：同词性、语义相近但搭配或逻辑不对，不要一眼假。
- `analysis` 用简体中文，讲清「为什么对、错误项为什么错」，并给出 `evidencePara` / `evidenceText` 指向原文。
